# Go 设计模式练习

[English](README.md)

22 个可独立阅读的 Go 示例，涵盖创建型、结构型和行为型设计模式。每个编号目录的 `main.go` 展示一种模式及其用法。

| 示例 | 建议关注 |
| --- | --- |
| [工厂](1_factory) | 通过统一接口创建具体车型。 |
| [代理](9_proxy) | 在示例处理器前加入请求检查和限流。 |
| [策略](14_strategy) | 在同一个缓存接口下切换 LRU、FIFO 和 LFU 淘汰策略。 |
| [观察者](17_observe) | 主题发生变化时通知已注册的观察者。 |

在仓库根目录使用支持通配符的 shell 运行以下示例。每个目录都是独立程序。

```sh
go run ./14_strategy/*.go
```
